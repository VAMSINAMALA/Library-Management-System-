# 📚 Library Management System

This is a Python-based command-line Library Management System developed using Object-Oriented Programming (OOP). It allows basic library operations like managing books, users, and borrowing activities.

---

## 🚀 Features Implemented

- Add books with ID, name, and quantity
- Display all books with available quantity
- Search books using keyword (case-insensitive)
- Add users
- Borrow books (if available)
- Return books
- Track which user borrowed which books
- Store transaction history (borrow & return with timestamp)
- Display users who borrowed books
- Show most borrowed book

---

## 🛠️ Technologies Used

- Python
- OOP Concepts (Classes & Objects)
- Lists and Dictionaries
- Command Line Interface (CLI)

---

## 📁 Project Files

- `main.py` → Entry point of the program  
- `operation_manager.py` → Handles menu and user interaction  
- `admin.py` → Core logic for books, users, and operations  
- `book.py` → Book class  
- `user.py` → User class  
- `utility.py` → Input validation
